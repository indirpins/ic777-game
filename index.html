Common Problems and How to Fix Them

Sometimes things do not work the first time. Here are a few common issues and simple fixes.

Problem: The page will not load.
Fix: Check your internet connection. Try refreshing the page or using a different browser.

Problem: Your password is not accepted.
Fix: Make sure the caps lock is not on. Try typing slowly or using the show password option to see what you typed.

Problem: You did not receive the verification code.
Fix: Wait a few minutes. Check your spam folder if you used email. If it still does not arrive, request a new code.

Problem: The app crashes during login.
Fix: Update the app to the latest version. If it still crashes, try uninstalling and reinstalling it. But only download from an official source.

Remember, if you see strange behavior like constant pop ups or requests for unusual permissions, stop using the app and report it.
